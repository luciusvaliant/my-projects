# Тест: Собеседование IT — Frontend / Backend / Fullstack

Веб-приложение для подготовки к собеседованию. Работает в любом браузере на любой ОС — без установки.

## Возможности

- **44 вопроса** по трём направлениям: Frontend, Backend, Fullstack
- Выбор направления: Все / Frontend / Backend / Fullstack
- Выбор технологий и языков: JavaScript, Python, Go, React, CSS, SQL, PostgreSQL, Docker, Kubernetes, Redis, Django, Node.js и др.
- Выбор количества вопросов: 5, 10, 15, 20 или все
- Два режима разбора:
  - **После каждого вопроса** — сразу виден правильный ответ и объяснение
  - **После всех вопросов** — разбор в конце теста
- **Порядок вариантов ответов перемешивается** при каждом показе вопроса
- Все варианты ответов одинаково подробны — правильный не выделяется длиной
- Случайный порядок вопросов при каждом запуске
- Результат в процентах с цветовой индикацией
- Полный список ответов с разбором в конце
- Адаптивный дизайн (телефон, планшет, десктоп)

## Запуск

### Способ 1: Просто открыть файл (без сервера)

Откройте `index.html` в любом браузере двойным кликом.

- **Windows**: двойной клик по `index.html`
- **Linux**: двойной клик или `xdg-open index.html`
- **Android**: перенесите `index.html` на телефон, откройте в Chrome/Firefox

> Для работы нужен локальный сервер (вопросы загружаются из `questions.json`).
> Без сервера приложение покажет сообщение об ошибке.

### Способ 2: Через локальный сервер (рекомендуется)

**Linux / macOS:**
```bash
python3 -m http.server 8080
```

**Windows (PowerShell):**
```powershell
python -m http.server 8080
```

Откройте `http://localhost:8080` в браузере.

### Способ 3: На телефоне через сервер

1. Запустите сервер на компьютере: `python3 -m http.server 8080`
2. Узнайте IP: `ip addr` (Linux) или `ipconfig` (Windows)
3. На телефоне: `http://<IP-компьютера>:8080`

## Формат вопроса в JSON

```json
{
  "id": 1,
  "direction": ["frontend", "fullstack"],
  "tags": ["JavaScript", "Общие"],
  "question": "Текст вопроса",
  "answer": "Подробный ответ для изучения",
  "options": ["Вариант A", "Вариант B", "Вариант C", "Вариант D"],
  "correctIndex": 0,
  "explanation": "Краткое объяснение"
}
```

- `direction` — одно или несколько из: `frontend`, `backend`, `fullstack`
- `tags` — технологии/языки для фильтрации
- `correctIndex` — индекс правильного ответа в массиве `options`
- Порядок вариантов перемешивается при каждом показе — `correctIndex` хранит исходный индекс

## Добавление вопросов

Отредактируйте `questions.json` — добавьте объект в массив `questions`. При запуске через сервер новая версия подгрузится автоматически.

> **Единый источник вопросов** — `questions.json`. В `index.html` нет встроенных вопросов, всё загружается через `fetch`.
