# Собеседование IT

Минимальное веб-приложение с карточками вопросов и ответов для подготовки к техническим собеседованиям.

## Возможности

- 3735 вопросов по категориям и технологиям.
- Выбор категории и количества вопросов: 5, 10, 15, 20, 30, 40, 50 или все.
- Случайный порядок карточек в каждом раунде.
- Ответ и отдельное пояснение для каждого вопроса.
- Адаптивный интерфейс для компьютеров и мобильных устройств.

## Запуск

Из каталога проекта запустите локальный HTTP-сервер:

```bash
python3 -m http.server 8080
```

Затем откройте `http://localhost:8080`.

Приложению нужен HTTP-сервер, потому что браузер загружает банк вопросов через `fetch('questions.json')`.

## Структура

```text
sobes/
├── README.md       # Описание и инструкция запуска
├── index.html      # Интерфейс приложения
└── questions.json  # Банк вопросов и ответов
```

## Формат вопроса

```json
{
  "id": 1616,
  "category": "Frontend (прочее)",
  "tags": ["frontend", "Performance", "middle"],
  "question": "Что такое кэширование в браузере и HTTP-заголовки?",
  "answer": "Подробный и самостоятельный ответ",
  "explanation": "Дополнительное пояснение и важные ограничения"
}
```

`questions.json` является единственным источником данных приложения. Для добавления или исправления карточки отредактируйте соответствующий объект в этом файле, сохранив уникальный `id`.
