# Rhinestone Studio — Генератор орнаментов из страз

Веб-приложение для создания орнаментов под выкладку стразами. Работает в любом браузере — без установки и сервера.

## Возможности

- **Два режима работы:**
  - **Готовые орнаменты** — генерация по алгоритмам с настройкой параметров
  - **Ручное рисование** — рисуйте мышью по холсту, стразы выкладываются по линиям
- **30+ видов орнаментов** в 5 группах:
  - Геометрические: круг, квадрат, звезда, спираль, меандр, волна и др.
  - Физические поля: магнитное поле, вихрь, галактика, интерференция, фрактал, кристалл
  - Орнаменты народов: исламский, кельтский, ацтекский, ранголи, африканский, китайский, скандинавский
  - Растительные: мандала, цветок, лотос, роза, древо жизни, лоза
  - Абстрактные: калейдоскоп, мозаика
- **Комбинирование** нескольких видов орнаментов в одной композиции
- Настройка осей симметрии (3–16), количества колец и плотности
- **8 цветовых палитр**: бриллиант, сапфир, рубин, изумруд, аметист, золото, радуга, закат
- **4 размера страз** по стандарту SS: SS6 (2 мм), SS10 (2.8 мм), SS16 (3.8 мм), SS20 (4.8 мм)
- Режим «Только схема» — контуры без отрисовки страз
- Сетка и статистика по количеству страз каждого размера
- **Экспорт в PNG** готовой схемы
- Адаптивный дизайн

## Запуск

Откройте `index.html` в любом браузере двойным кликом — сервер не нужен, всё работает локально.

- **Windows**: двойной клик по `index.html`
- **Linux**: двойной клик или `xdg-open index.html`
- **Android**: перенесите папку на телефон, откройте `index.html` в Chrome/Firefox

## Как пользоваться

1. Выберите один или несколько видов орнаментов на вкладке «Готовые орнаменты».
2. Настройте симметрию, кольца и плотность для активного вида.
3. Подберите палитру и включите нужные размеры страз.
4. Нажмите «Новый орнамент» для другой вариации (генерация случайная).
5. Скачайте результат кнопкой «Скачать PNG».

Для ручной выкладки переключитесь на вкладку «Ручное рисование», нарисуйте линии мышью и нажмите «Показать стразы».
